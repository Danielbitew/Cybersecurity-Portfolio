# AI-Assisted Phishing Campaign Investigation

## Project Overview

This project demonstrates how artificial intelligence can support a phishing investigation by organizing reported emails, identifying related campaign activity, and producing structured, evidence-based findings.

## Objective

The objective was to identify the most significant phishing campaign, analyze the available evidence, and determine which messages required further investigation.

## Tools and Methods

- AI-assisted analysis
- Email campaign correlation
- Prompt refinement
- Evidence validation
- Organizational policy context
- Analyst review

## Investigation Process

1. Reviewed reported phishing emails and grouped related messages into campaigns.
2. Prioritized the campaign that affected multiple departments and contained the largest group of related reports.
3. Refined the AI prompt to produce a more structured and evidence-based analysis.
4. Added organizational context so the AI could interpret the campaign using internal policies and procedures.
5. Compared AI conclusions with the available evidence before making a final determination.

## Key Findings

- Related phishing emails can be grouped into a single campaign for more efficient investigation.
- AI-generated conclusions should be validated using analyst judgment and supporting evidence.
- Organizational context improves the usefulness of AI-assisted analysis.
- Structured prompts produce clearer and more actionable investigation results.

## Skills Demonstrated

## Ethical and Security Considerations

This project contains only academic and simulated material. No confidential employer information, credentials, personal data, or active phishing content is included.
