# AI System Failure Investigation

## Project Overview

This project demonstrates how artificial intelligence can support the investigation of system failures by analyzing deployment configurations, retrieval thresholds, and supporting evidence before making engineering decisions.

## Objective

Investigate the root cause of an AI system failure by comparing deployment configurations, validating AI recommendations, and evaluating retrieval performance.

## Tools and Methods

- AI-Assisted Analysis
- Retrieval-Augmented Generation (RAG)
- Similarity Threshold Evaluation
- Deployment Comparison
- Engineering Validation
- Root Cause Analysis

## Investigation Process

1. Reviewed deployment configurations and retrieval settings.
2. Compared multiple similarity threshold values.
3. Evaluated the effect of threshold changes on retrieval quality.
4. Correlated evidence from multiple sources.
5. Identified the underlying configuration responsible for the failure.
6. Validated AI recommendations using engineering judgment.

## Key Findings

- High AI confidence does not guarantee a correct result.
- Engineering decisions should be supported by testing and evidence.
- Retrieval thresholds directly affect the balance between relevant and irrelevant information.
- Multiple failure symptoms can originate from the same configuration change.
- AI recommendations should always be verified before production deployment.
