# AI-Assisted Endpoint Investigation

## Project Overview

This project demonstrates how artificial intelligence can support endpoint security investigations by helping analysts review events, identify suspicious activity, and compare AI predictions with analyst-verified outcomes.

## Objective

The objective was to evaluate endpoint events and determine which activities required additional investigation based on technical evidence and analyst review.

## Tools and Methods

- AI-assisted event classification
- Endpoint telemetry analysis
- Behavioral evidence review
- Severity assessment
- Process relationship analysis
- Confusion matrix evaluation
- Precision and recall analysis

## Investigation Process

1. Reviewed endpoint events and their associated severity, confidence scores, and behavioral evidence.
2. Examined process relationships to understand parent-child activity and possible suspicious execution patterns.
3. Compared AI-generated classifications with analyst-verified outcomes.
4. Created a confusion matrix to identify true positives, false positives, true negatives, and false negatives.
5. Evaluated precision and recall to assess the effectiveness of the AI model.
6. Identified events that required further analyst investigation.

## Key Findings

- High AI confidence does not automatically mean an event is malicious.
- Analyst verification remains essential when evaluating endpoint activity.
- Behavioral evidence, severity, and process relationships provide important investigative context.
- Precision and recall help measure whether the model generates too many false alerts or misses suspicious events.
- AI should support, not replace, human cybersecurity judgment.
