# AI-Assisted Network Traffic Analysis

## Project Overview

This project demonstrates how artificial intelligence and data analytics can assist in identifying suspicious network activity by analyzing connection data, recognizing anomalies, and prioritizing events for further investigation.

## Objective

Analyze network traffic to identify unusual communication patterns, suspicious destinations, and abnormal behavior that may indicate potential security threats.

## Tools and Methods

- Python
- Pandas
- Data Visualization
- AI-Assisted Analysis
- Network Traffic Analytics
- Statistical Analysis

## Investigation Process

1. Imported and cleaned network traffic data.
2. Created new features such as total bytes transferred.
3. Filtered and sorted network events.
4. Generated visualizations to identify unusual behavior.
5. Flagged candidate events requiring further investigation.
6. Evaluated suspicious connections using AI-assisted analysis.

## Key Findings

- Large data transfers can indicate potential data exfiltration.
- After-hours network activity deserves additional investigation.
- Long connection durations may represent abnormal behavior.
- Destination countries outside normal business operations require review.
- AI improves analyst efficiency by highlighting suspicious activity.
