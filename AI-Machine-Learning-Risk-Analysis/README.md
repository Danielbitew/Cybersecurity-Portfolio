# AI-Assisted Machine Learning Risk Analysis

## Project Overview

This project demonstrates how machine learning techniques can support cybersecurity by evaluating user and network behavior to calculate risk scores and identify potentially suspicious activity.

## Objective

The objective was to analyze cybersecurity data using machine learning concepts, generate risk scores, and evaluate how decision thresholds affect detection performance.

## Tools and Methods

- Python
- Pandas
- Machine Learning
- Risk Scoring
- Data Visualization
- AI-Assisted Security Analysis

## Investigation Process

1. Loaded and analyzed cybersecurity datasets.
2. Calculated risk scores based on multiple behavioral features.
3. Applied different decision thresholds.
4. Compared model predictions with expected outcomes.
5. Evaluated false positives and false negatives.
6. Documented the effect of changing thresholds on detection performance.

## Key Findings

- Machine learning improves the ability to identify suspicious behavior.
- Decision thresholds directly affect precision and recall.
- Lower thresholds increase detections but may create more false positives.
- Higher thresholds reduce false positives but may miss threats.
- Human validation remains essential before making security decisions.
